# Gt — Colour Gamut

A visual colour-gamut tool for extracting palettes from images, building colour combinations, naming them, and exporting colour specifications.

## A product statement for iTCs

creating a problem to watch it get solved

colour is simple, hardly manmade but captured by all organisms epic and microscopic.

Humans however, have an edge on colour when it comes to selection and bias.

Gt dissolves the bias in identifying them, we identify things for ourselves and share that external identity for cultural effects.

iTCs - image to colour systems
